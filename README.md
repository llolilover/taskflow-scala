# TaskFlow — Scala 3 backend

Учебный backend-сервис для управления задачами с типобезопасной предметной областью и контролем версий.

## Что реализовано

- Чистая доменная модель на Scala 3: `opaque type`, `enum`, `Either`, правила переходов.
- HTTP API на http4s и Circe: создание, список, получение и изменение статуса.
- Временное хранилище на Cats Effect `Ref` с атомарной проверкой `expectedVersion`.
- Unit-тесты доменной модели и тесты сервиса, включая конкурентные обновления.
- GitHub Actions для автоматической проверки сборки и тестов.

## Запуск

Требуются JDK 21 и sbt.

```bash
sbt test
sbt run
```

В другом терминале:

```bash
curl -i http://127.0.0.1:8080/health
bash scripts/smoke.sh
```

Описание маршрутов, JSON и кодов ошибок: [docs/API.md](docs/API.md).

## Архитектура

`TaskRoutes` (HTTP и DTO) → `TaskService` (операции и проверка версий) → `Ref[IO, Map[TaskId, Task]]` (хранилище в памяти).

Бизнес-правила описаны в чистой доменной модели `Task` и `TaskRules`.

## Ограничения и дальнейшие этапы

**Данные пока не сохраняются между перезапусками.** Атомарная проверка версии через `Ref.modify` действует только внутри одного процесса, не между несколькими экземплярами сервиса.

План: PostgreSQL + Doobie, история статусов в одной SQL-транзакции, интеграционные тесты с реальной БД и Docker Compose.

Проект учебный и ещё развивается; не является production-сервисом.
