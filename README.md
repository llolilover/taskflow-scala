# TaskFlow — Scala 3 backend

Учебный backend-проект для подготовки к Scala-стажировке. Разработка ведётся по этапам; реализованные компоненты добавляются последовательными коммитами.

## Цель

REST API управления задачами с типобезопасной моделью, проверкой переходов статусов и защитой от конкурентных изменений.

## Планируемый стек

- Scala 3, sbt, MUnit
- Cats Effect, http4s, Circe
- Doobie, PostgreSQL, Docker Compose
